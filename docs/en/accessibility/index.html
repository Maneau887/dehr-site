Accessibility statement

Updated: 28 October 2026

DEHR Ltd wants everyone to be able to use this website, including people with disabilities. The site was built in line with Israel's Equal Rights for Persons with Disabilities (Service Accessibility Adjustments) Regulations, 2013, and Israeli Standard IS 5568, which is based on WCAG 2.0 level AA.

What we have done

  • The site is available in Russian, Hebrew (right-to-left) and English; each version has its own address and the page language is set correctly.
  • Everything can be used with a keyboard and the focus is clearly visible. A "Skip to content" link is at the top of each page.
  • Headings and regions are marked up so screen readers read them correctly.
  • Text colours have sufficient contrast.
  • The job map is backed by a list of cities, so all information is available without the map.
  • The site adapts to screen size and text zoom, and animations are turned off when "reduce motion" is enabled.

Known limitations

  • The map background is a third-party service that screen readers cannot fully read. Please use the list of cities next to the map.
  • Job photos are decorative: all job information is in the card text.

If something doesn't work

If you have trouble using the site or find an accessibility problem, write or call us and we'll help and fix it. Accessibility contact: DEHR Ltd management, phone and WhatsApp +972 54-873-2037, Telegram @dehrcompany.
