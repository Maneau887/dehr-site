# Сайт DEHR Ltd (dehr.ltd)

Статический сайт на трёх языках: `/` — русский, `/he/` — иврит, `/en/` — английский.
Хостинг — GitHub Pages. Публикуется папка `docs/` из ветки `main` (её собирает `python build.py`).

## Как обновить вакансии

1. Откройте `src/jobs.json`.
2. Каждая вакансия — один блок:
   - `id` — номер (DH-208 и т.д.), показывается на карточке и в сообщении WhatsApp;
   - `cat` — отрасль: `fac` производство, `food` кейтеринг и мероприятия, `clean` клининг, `auto` автосервис, `build` стройка, `wh` склад;
   - `cities` — ключи городов из блока `cities` вверху файла; новый город добавляется туда с координатами `ll: [широта, долгота]` и названиями на трёх языках;
   - `pay` — `{"amount": 50, "per": "hour"}` или `{"amount": 12000, "per": "month"}`;
   - `house` — `true` (жильё есть), `"paid"` (платное), `false` (нет);
   - `who` — `"m"` (мужчины) или `"all"` (мужчины и женщины);
   - `photo` — `"photos/dh-208.jpg"` (файл кладётся в `public/photos/`); без фото уберите строку — будет обложка отрасли;
   - `posted` — дата публикации `ГГГГ-ММ-ДД`;
   - `ru` / `he` / `en` — `title`, `desc`, `tags`, `docs`, по желанию `lang`.
3. Запустите `python build.py` — сборка проверит города и фото и обновит `docs/`. Затем закоммитьте и отправьте изменения в GitHub — сайт обновится за 1–2 минуты.

Фильтры по отраслям и точки на карте строятся сами из списка вакансий.

## Тексты, контакты, юридические страницы

- Все тексты страниц: `src/strings.json` (ru / he / en).
- Телефон, Telegram, соцсети, Яндекс Метрика, ссылка на отзывы Google: вверху `build.py`.
- Номер лицензии: ключ `ft_lic` в `src/strings.json` (пока пустой — строка не показывается).
- Политика конфиденциальности и заявление о доступности: `src/legal/*.html`.

## Служебное

- `python tools/fetch_assets.py` — один раз скачивает шрифты и библиотеку карты в `public/assets/`.
- `python tools/make_images.py` — иконки и картинка для соцсетей (`og.png`).
- Карта: MapLibre GL JS + бесплатная подложка OpenFreeMap (без ключа, коммерческое использование разрешено, подпись © OpenStreetMap обязательна).
- Яндекс Метрика загружается только после согласия посетителя.
- Заявок через форму нет: кнопки «Откликнуться» открывают WhatsApp с готовым сообщением и номером вакансии.
